# Gallery QA Checklist

Run through these checks before publishing a Gallery update.

## Media browsing

- Open image, video, and mixed folders.
- Confirm empty albums render without layout breakage.
- Test large folders for scrolling and thumbnail stability.
- Rotate the device and confirm the selected media remains visible.

## Media actions

- Open media details.
- Share a photo and a video.
- Delete or move media only in a safe test folder.
- Confirm permission prompts are understandable.
